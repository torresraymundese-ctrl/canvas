# 导演画布产品审查

## 审查范围

- 产品表面：AI 短剧导演画布主界面。
- 用户目标：从剧本导入开始，经导演拆解、视觉设定和分镜确认，最终稳定生成可回看的成片。
- 证据截图：`audit/01-current-canvas.png`。
- 审查方式：主画布截图审查、当前前端能力检查、同类节点工作流与火山方舟任务模型对照。

## 流程步骤

1. **进入第 1 集主画布 — 健康度：基础良好，但尚未形成生产闭环。**
   - 导演 Agent、手动画布、预算、三阶段流程和节点状态的总体结构清楚。
   - 当前只覆盖主画布可见状态；节点编辑、失败状态、生成队列和最终导出没有完整截图证据。

## 已经做对的地方

- “故事理解 → 视觉设定 → 镜头生成”的阶段划分适合非技术创作者理解。
- 导演模式与手动模式并存，既能让 Agent 自动推进，也保留人工修改入口。
- 节点卡片直接展示视觉结果，比分离式表单更适合图片和视频创作。
- 预算、状态、模型和确认动作已经出现在正确的产品层级中。

## P0：接入真实模型前必须补齐

1. **真实项目保存、恢复与版本历史。** 目前界面显示“已自动保存”，但前端没有持久化；刷新会丢失自由节点、位置、连线和备注。应保存项目、节点、边、视口、模型配置和资产引用，并提供恢复点。
2. **可执行的节点数据协议。** 每个节点需要明确输入、输出、参数、依赖和校验规则；连线不能只负责视觉连接，还要阻止类型不匹配、缺失输入和循环依赖。
3. **生成任务中心。** 为每次图片或视频生成保存任务 ID、排队/运行/成功/失败/取消状态、进度、耗时、费用、错误原因和重试入口。火山方舟视频任务本身就具备这些异步状态，因此画布需要对应的队列层。
4. **完整节点参数编辑器。** 至少包含模型、提示词、反向提示词、比例、分辨率、时长、帧率、种子、参考图和首尾帧；节点卡片只显示摘要，右侧检查器负责完整编辑。
5. **资产与结果版本管理。** 上传素材、生成结果、缩略图和视频不能只保存在浏览器内存中；需要对象存储、元数据、版本、失效处理，以及“设为当前版本”。
6. **导演 Agent 的结构化审批。** 导演输出应拆成可编辑的角色表、场景表、分镜表和提示词，而不是只返回聊天消息；每一阶段支持确认、退回、差异对比和局部重做。

## P1：让创作效率真正超过普通表单

1. 单节点运行、运行到此节点、从此节点继续、只重跑失败节点。
2. 镜头批量生成、候选版本并排比较、收藏、淘汰和设为最终结果。
3. 角色身份、服装、场景色调和画面比例的项目级一致性锁定。
4. 节点删除、复制、粘贴、批量选择、分组、对齐、折叠和模板保存。
5. 工作流搜索、节点目录、定位选中节点、画布书签和“一键适应全部内容”。
6. 任务队列抽屉、生成历史、成本明细和失败日志。
7. 导出分镜表、提示词包、素材包、单镜头视频和整集成片。

## 目前界面最需要修改的地方

1. **单击与双击职责重叠。** 建议单击节点只负责选中并打开右侧参数；双击才进入图片、剧本或视频的全屏查看器。现在单击同时触发查看器和参数状态，容易打断连续编辑。
2. **低缩放下信息不可读。** 56% 时节点文字已经很小；应做语义缩放：低于 40% 只显示标题、状态和缩略图，40%–70% 显示摘要，高于 70% 才展示完整参数。
3. **“自动生成整集”风险过高。** 点击前应先出现运行前检查，列出待运行节点、缺失输入、预计费用和时间，并让用户选择“全部运行”或“只运行未完成节点”。
4. **左侧 Agent 信息过密。** 将聊天记录与执行进度拆开；默认展示当前计划、待确认事项和失败任务，历史消息折叠。
5. **状态信息重复且分散。** 节点、左栏和底部图例都在表达状态。保留节点状态，将全局状态集中到任务队列抽屉。
6. **新增节点发现性不足。** 保留双击，同时增加固定“＋ 添加节点”按钮和快捷键提示；模板、素材库和生成历史应成为可搜索侧栏。
7. **画布缺少导航层。** 在大画布中加入选中对象定位、返回上次位置、分区折叠和搜索，否则节点增加后会快速迷失。

## 无障碍风险

- 截图中大量辅助文字约为 8–10px，灰色文字与深色背景对比偏弱。
- 多个控制按钮约为 30px，触控目标偏小。
- 状态过度依赖绿色、蓝色、黄色；应同时保留文字或图标。
- 需要实际键盘测试焦点顺序、快捷键、节点拖动替代方式和视频播放器可操作性；截图不足以证明完整无障碍表现。

## 对照依据

- ComfyUI 将节点库、已保存工作流、模板、任务队列和生成历史作为基础界面能力：https://docs.comfy.org/interface/overview
- ComfyUI 的执行接口会先校验节点，再进入队列，并提供历史、停止与实时状态：https://docs.comfy.org/development/comfyui-server/comms_routes
- React Flow 官方提供连接校验、撤销重做、复制粘贴和拖放节点等成熟交互模式：https://reactflow.dev/examples/interaction/validation
- 火山方舟视频任务返回 queued、running、cancelled、succeeded、failed、错误信息和用量，画布状态模型应直接覆盖这些状态：https://api.volcengine.com/api-docs/view?action=GetContentsGenerationsTask&serviceCode=ark&version=2024-01-01

## 推荐实施顺序

1. 项目持久化、真实自动保存、撤销与重做。
2. 节点数据协议、参数编辑和连线校验。
3. 火山方舟适配器、任务队列、取消与重试。
4. 资产存储、候选版本对比与结果追溯。
5. 导演 Agent 结构化输出与阶段审批。
6. 批量分镜生产、整集编排和导出。

## 证据限制

本次只接受了用户提供的主画布截图，无法从截图验证完整节点编辑、失败恢复、键盘操作、响应式布局和整集导出流程。因此以上“缺失功能”同时参考了当前前端实现；无障碍结论仅为风险提示，不代表完整 WCAG 审核。
